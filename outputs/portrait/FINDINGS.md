# Phase portrait — preliminary findings

**Status: preliminary, and deliberately UNBOUNDED.** OSDR's `p_correction = c_k · d_k^n`
is *not* applied. Spec §5 says to check confinement first and add the correction only as a
flagged sensitivity variant; the check is reported below and it **fails for two of nine
archetypes**, so every statement about the high-density branch is extrapolation-sensitive
and should be revisited once the OSDR-style maximal-density bound is in.

> ### Upstream caveat discovered while running the test suite
>
> Spec 6.7's **Test 07 — the critical size-confound test — fails at the spec's own sample
> size** on the fold criterion. On simulated data with `pi_i == 0` (no latent classes at
> all), n = 100,000, the model returns a rate ratio of **6.374** (threshold 1.5), entropy
> 0.3143 (threshold 0.25), with `mean(w) = 0.584`. σ₁(B̂) = 0.0448 against a null reference
> of 0.0693 does pass, so the *interaction* structure is not invented — only the rate split.
>
> The real-data fit's rate ratio is **5.630**, i.e. **smaller than the class-free floor**.
> An earlier defence of this test in this project — that the floor was 1.93 and the real
> fold sat 2.9× above it — was measured at reduced scale and does not hold at spec scale.
>
> This is one seed. Note also that the two scales disagree about *which* criterion fails
> (at n = 30,000: fold 1.27 passes but σ₁ = 776 fails; at n = 100,000: fold 6.37 fails but
> σ₁ passes), which points at an optimisation/convergence problem rather than a clean
> signal — the config already records that nothing converged at 2000 iterations below
> `weight_ridge = 100`. **Convergence should be checked before concluding anything about
> the model.** Spec 6.7 is explicit that a genuine failure here is not a tuning problem and
> must be resolved before real-data results are reported, so this bears on the mixture fit
> the portrait is built on, not only on the portrait.

## 1. What the portrait is

The fitted mixture gives P(cycling) for a cell of state `φ` in a neighbourhood of
composition `φ̄` at density `n`. Spec §2–3 turn that into a deterministic field over
archetype densities `X ∈ R^9`, `X_k` = density of archetype *k*:

```
F_k(X) = X_k · (π_k(X) − π̄_k) / τ_k ,     π_k(X) = expit(η(A_k, φ̄(X), n(X)))
φ̄(X) = (X/n)·A ,   n(X) = Σ_j X_j ,   τ_k = 1
```

`π̄_k` is the death anchor, spec §3.2's loading-weighted mean of the fitted `π̂`. It is
**not estimated from death data** — it is the assumption that division balances death on
average. Everything below is conditional on it.

- 678,885 cells, 9 `celltype_major` archetypes, oxygen frozen at its median.
- Archetype reconstruction **R² = 1.000000** — exact, because 9 archetypes in the
  8-dimensional sum-to-zero subspace plus sum-to-one is a square system. Nothing is
  discarded (spec §12.4 is satisfied trivially).
- `Ã = A B Aᵀ` has singular values **[2.178, 1.480, 0, 0, …]** — rank 2, inherited from
  `rank(B) = 2`. The entire 9×9 interaction structure lives in a 2-dimensional subspace.

### Caveat that constrains every reading below

The exactness of the reconstruction is bought with a **non-convex** representation. The
barycentric loadings are the solution of a square linear system, not a non-negative fit:

- **28.0%** of loading entries fall outside [0, 1];
- only **3.2%** of cells have all nine `X_k > 0`;
- the observed tumour fraction has **q25 = −0.035** — negative.

So `X_k` is a *signed pseudo-density*, and "density of archetype k" is literal only where
the loadings happen to be positive. Pairwise this is much less severe (301k–380k cells have
both swept coordinates positive), which is why the pairwise slices remain usable, but the
9-dimensional state is not a simplex and should not be described as one.

## 2. Headline: the flow does not self-confine, and OSDR's correction is needed

Spec §5's confinement check, `dη/d(log n)` at the 90th percentile of density:

| archetype | slope | | archetype | slope |
|---|---|---|---|---|
| Endothelial | −0.877 confining | | Myeloid | −0.515 confining |
| CAFs | −0.207 confining | | Normal Epithelial | −0.559 confining |
| PVL | −0.605 confining | | **Plasmablasts** | **+0.913 outward** |
| B-cells | −0.598 confining | | **Cancer Epithelial** | **+1.199 outward** |
| T-cells | −0.443 confining | | | |

Seven of nine archetypes are confining at high density. **The two epithelial/secretory
archetypes are not** — their cycling odds keep rising with crowding, so the flow escapes
rather than saturating.

This is exactly the failure mode OSDR bolted `p_correction` on to suppress. Two things
follow. First, the honest answer to "is our estimated density spline an advantage over
OSDR's ad-hoc bound?" is **no, not universally** — it is an advantage for seven archetypes
and reproduces OSDR's problem for the two that matter most clinically. Second, the
high-density branch of every result below is the part the bound would change.

## 3. Density thresholds: an Allee structure in stroma, escape in tumour

Sweeping total density at each archetype's *own* mean neighbourhood composition, and
finding where `π_k = π̄_k`:

| archetype | lower crossing | upper crossing | structure |
|---|---|---|---|
| Endothelial | n=79 (p47) unstable | n=151 (p88) stable | Allee + ceiling |
| PVL | n=79 (p47) unstable | n=156 (p89) stable | Allee + ceiling |
| B-cells | n=76 (p44) unstable | n=145 (p86) stable | Allee + ceiling |
| T-cells | n=88 (p57) unstable | n=154 (p89) stable | Allee + ceiling |
| Normal Epithelial | n=84 (p52) unstable | n=160 (p91) stable | Allee + ceiling |
| **Plasmablasts** | — | n=151 (p88) **unstable** | **escape only** |
| **Cancer Epithelial** | — | n=152 (p89) **unstable** | **escape only** |
| CAFs | — | — | always shrinks |
| Myeloid | — | — | always shrinks |

Five archetypes show a textbook **Allee effect**: extinction below n≈80 (about the median
density), growth toward a stable carrying capacity at n≈150 (about the 88th percentile).

Cancer Epithelial and Plasmablasts have **no ceiling at all**. Their single crossing at
n≈152 is an *escape threshold*: below it they shrink, above it they grow without bound.
That single sign difference is the whole content of §2.

CAFs and Myeloid never cross at their own composition — which is why the CAF × Myeloid
slice, the direct OSDR replication target, contains **no nullcline anywhere in support**
and the flow is uniformly co-expanding.

## 4. The tumour's growth ceiling exists only in a narrow composition window

At the q50 *mixed* composition the tumour compartment does have a stable ceiling
(`X_CE ≈ 37.5`, n ≈ 84), and the boundary fixed points confirm it: `X_CE = 37.5` against
CAFs, `35.2` against Myeloid, `27.7` against T-cells. But at the tumour's *own* composition
that equilibrium is absent (§3). Blending the neighbourhood composition between the two
resolves the contradiction — it is a **saddle-node bifurcation at both ends of a window**:

> A stable density ceiling for Cancer Epithelial exists **only for tumour fraction
> 0.266 ≤ w̄_CE ≤ 0.493**. Outside that window there is only an escape threshold.

Where the observed neighbourhoods actually sit:

| regime | tumour fraction | share of cells |
|---|---|---|
| below the window — tumour-poor, invasion front | w̄_CE < 0.266 | **69.0%** |
| **inside the window — growth is controlled** | 0.266–0.493 | **12.4%** |
| above the window — tumour core | w̄_CE > 0.493 | **18.5%** |

So the model infers that proliferative control over the tumour compartment is present in
only about an eighth of neighbourhoods, and is lost in *both* directions — at the sparse
invasion front and in the dense core. Where it exists, the ceiling sits at n = 75–109 cells
per (100 µm)², the 43rd–71st percentile of observed density.

`composition_bifurcation.png` shows the full S-curve; `run/portrait_bifurcation.py`
regenerates it, with the crossings per composition in `composition_bifurcation.csv`.

This is the most interesting result here, and also the one most exposed to the missing
bound: the upper saddle-node at w̄_CE ≈ 0.49 is precisely where the non-confining density
response takes over.

## 5. Nullclines are near-degenerate because they are density contours

Total density `n` along each zero contour barely varies:

| slice | nullcline | mean n | cv |
|---|---|---|---|
| CE × CAFs | Cancer Epithelial | 83.9 | **0.061** |
| CE × Myeloid | Cancer Epithelial | 82.5 | **0.085** |
| CE × T-cells | Cancer Epithelial | 82.5 | 0.195 |
| CE × T-cells | T-cells | 73.0 | 0.205 |
| CAFs × Myeloid | either | — | no contour in window |

A nullcline spanning two orders of magnitude in `X_k` while `n` moves by 6% *is* a density
contour. The density spline, not the interaction matrix, is the dominant control on `π`.

The consequence is geometric: two nullclines in the same slice are two nearly-parallel
density contours, so their intersection is ill-conditioned. The angle between the nullcline
gradients at the 80th percentile:

| slice | angle |
|---|---|
| CAFs × Myeloid | **1.33°** — effectively degenerate |
| CE × T-cells | 19.2° |
| CE × CAFs | 32.7° |
| CE × Myeloid | 45.6° |

CAF × Myeloid is degenerate to within 1.3°: the two archetypes have almost the same density
response, so no isolated fixed point can form between them at any composition. **This is a
negative result for the OSDR replication** — the CAF/Myeloid bistability OSDR reports is not
recovered here, and the reason is identifiable rather than mysterious.

## 6. Fixed points

Across all 12 masked panels (4 priority pairs × q25/q50/q75), **zero interior fixed points
lie inside the support mask**. One interior saddle is found at q25 in CE × T-cells
(`X_CE=25.1, X_T=26.1`, n=47.4, reduced max Re λ = +0.050) but it falls outside support.
Four boundary (single-type) fixed points are found on invariant faces, all involving Cancer
Epithelial. Full table in `fixed_points.csv`.

The absence is a real property of the supported region, not a search failure: §5 explains
why interior crossings are ill-conditioned, and the all-pairs contact sheet shows the
nullclines *do* intersect — consistently in the extreme top-right corner, beyond support.

**Support.** Masked fraction is 0.56–0.90 at q25/q50 and **1.00 at q75**. The q75 slices are
entirely unsupported (5–39 cells survive the held-coordinate band, against 14k–30k at q50),
so spec §7's topology-robustness check across reference levels **cannot be run** on this
dataset — only q25 vs q50 can be compared, and those agree (zero supported interior points).

Two deviations from spec §5 worth recording:
- The `min_cells = 20` rule is counted on a coarse 30×30 support grid, not the 150×150
  plotting grid. On the plotting grid it would require 450k conditioned observations to
  average 20 per bin, and masks 100% of every panel.
- Conditioning on seven held coordinates at once is what kills q75; this is a
  dimensionality limit of slice-based support, not a property of the model.

## 7. The interaction matrix `Ã = A B Aᵀ`

Rank 2, mostly reciprocal (symmetric / antisymmetric Frobenius norms 2.457 / 0.947).
Largest entries, in log-odds of cycling per unit neighbourhood fraction:

| effect | value |
|---|---|
| B-cells ← Cancer Epithelial | **+0.690** |
| Plasmablasts ← Endothelial | **−0.701** |
| Cancer Epithelial ← PVL | +0.501 |
| T-cells ← Cancer Epithelial | +0.483 |
| Cancer Epithelial ← T-cells | +0.451 |
| Normal Epithelial ← Cancer Epithelial | −0.434 |

Two things stand out.

**Cancer Epithelial and T-cells are mutually stimulating** (+0.483 and +0.451) — a
reciprocal proliferation loop, not the antagonism a naive immune-control model predicts.

**Cancer Epithelial has the most negative self-term (−0.674)**, the strongest on the
diagonal. Compositional crowding by other tumour cells *suppresses* tumour cycling even
though total-density crowding promotes it (§2). These are opposite-signed channels acting
through different covariates, and separating them is only possible because the weight model
carries both `φ̄` and `n`.

## 8. Validation

All 13 spec §11 tests pass (`tests/test_portrait.py`), including the two blocking ones that
were outstanding.

- **§11.2 analytic Jacobian.** Passes at 2.7e-08. The earlier 3.9e-05 failure was the
  *test's* finite-difference probe, not the Jacobian: a relative step of 1e-6 is too small
  for the smaller state components (at 1e-7 cancellation gives 1.6e-05). The probe now takes
  the best of steps 1e-4/1e-5/1e-6.
- **§11.6 known-system recovery.** All five planar topologies are recovered — stable node,
  stable spiral, saddle, unstable node, unstable spiral — a superset of OSDR Fig. 2d's four.
  Deriving the parameters produced a small result worth keeping: with **equal** death anchors
  an unstable interior point is *impossible* in this model class, because `det > 0` requires
  `μ_a < μ_b` while `trace > 0` requires `γ_a μ_a > γ_b μ_b` with `γ_k = π̄_k(1−π̄_k)`.
  An exhaustive sweep of 20,480 parameter sets at `π̄ = (.5,.5)` finds none, confirming it.

**§11.4 is implemented in a corrected form, and this is a real deviation.** As written the
test asks for `|F_k|` to be small at archetype *k*'s loading-weighted mean state, justified
by the mean value theorem. That justification does not hold: `π̄_k` averages `π` over cells
while `π_k` is nonlinear in `X`, so the mean state is not a state where `π_k = π̄_k`
(Jensen). Measured, the as-written ratio is 0.44–0.58 for CAFs and Plasmablasts under
*every* anchor definition tried — signed, vertex-evaluated, and clipped — so it is not the
weighting error the spec suggests. The test now asserts the property anchoring actually
buys (spec §12.2): `π̄_k` lies strictly inside the observed range of `π_k`, i.e. each
nullcline passes through the data cloud. That passes for all nine archetypes.

`π̄` uses spec §3.2's signed-loading formula. Clipping the 28% negative loadings shifts each
anchor by at most 0.017 (`pi_bar_clipped` in the manifest); it moves the tumour equilibrium
from `X_CE ≈ 37.5` to `≈ 47`, so it belongs in the sensitivity sweep.

## 9. Not yet done

- **Spec §8, uncertainty — none of it.** No parametric bootstrap, no spatial block
  bootstrap, no topology-preservation fraction. **Every number above is a point estimate
  with no interval**, and the headline of §4 (a window with two saddle-node ends) is exactly
  the kind of claim that needs one.
- **Spec §9, sensitivity grid — none of it.** The `π̄` multiplier, calibration and `δ`
  perturbations, radius/`L0` refits, oxygen reference, `K`, `own_state_mode` and `τ` axes are
